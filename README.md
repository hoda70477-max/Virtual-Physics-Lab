\# 🔬 PhysLab – Virtual Physics Laboratory



\*\*PhysLab\*\* is a desktop application developed using C# and WPF. It provides a virtual environment for exploring and simulating fundamental physics experiments.



The project combines physics concepts with Object-Oriented Programming (OOP), allowing users to perform experiments, calculate results, and save their records.



\## ✨ Features



\- \*\*Simple Pendulum:\*\* Explore pendulum motion and its physical properties.

\- \*\*Spring-Mass System:\*\* Simulate spring behavior and related calculations.

\- \*\*Projectile Motion:\*\* Explore the motion of a projected object.

\- \*\*Newton's Second Law:\*\* Calculate acceleration, momentum, and weight.

\- \*\*Save Results:\*\* Store experiment results locally using JSON.

\- \*\*Saved Results:\*\* View previously saved experiment records.

\- \*\*Experiments Dashboard:\*\* Navigate between the available experiments.



\## 🛠️ Technologies Used



\- C#

\- .NET 10

\- Windows Presentation Foundation (WPF)

\- XAML

\- JSON



\## 🧩 Object-Oriented Programming Concepts



The project demonstrates key OOP concepts:



\- \*\*Encapsulation:\*\* Organizing data and controlling access to object properties.

\- \*\*Inheritance:\*\* Reusing shared behavior through class relationships.

\- \*\*Polymorphism:\*\* Supporting flexible experiment behavior.

\- \*\*Abstraction:\*\* Organizing experiment logic into clear class structures.

\## 🚀 Getting Started



\### Requirements



\- Windows

\- Visual Studio with the .NET desktop development workload

\- .NET 10 SDK



\### Run the Project



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/hoda70477-max/Virtual-Physics-Lab.git

&#x20;  ```



2\. Open `PhysLab.slnx` in Visual Studio.

3\. Build the solution.

4\. Run the application.



\## 💾 Data Storage



Experiment results are stored locally in JSON format at:



```text

%LOCALAPPDATA%\\PhysLab\\saved\_experiments.json

```
